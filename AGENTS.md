# Prosjektinstruksjoner

- Bruk denne mappen som selvstendig Git- og prosjektrot. Bruk relative stier.
- Ikke bruk Sites eller opprett Sites-konfigurasjon. Første offentlige skisse
  bruker GitHub Pages. Ingen automatisk commit eller push; etter første
  publisering kreves uttrykkelig bestilling for ny commit og push.
- Hold kundeunderlag, avtale, kravspesifikasjon, fakturainformasjon og private
  filer lokalt. Ikke aktiver skjema, bestill domene eller endre DNS/e-post uten
  uttrykkelig avklaring.
